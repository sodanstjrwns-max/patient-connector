# Patient Connect 알림톡 템플릿 (솔라피 등록용)

발신 채널: patientconnect (Patient Connect) · 카테고리: 서비스이용 > 이용안내/공지 · 유형: 기본형 · 대체발송 안 함

## 템플릿 이름
진료 안내장

## 본문
```
[#{병원명} 진료 안내]
#{환자명}님, 안녕하세요. #{병원명}입니다.
오늘 내원해 설명드린 진료 자료와 주의사항을 보내드립니다.
상담 시 요청하신 대로 아래 버튼에서 언제든 다시 확인하실 수 있습니다.

궁금한 점은 병원으로 편하게 문의해 주세요.
문의: #{병원전화}
※ 이 메시지는 #{병원명}의 요청으로 'Patient Connect'가 발송합니다.
```
- 버튼: 웹링크 「안내자료 확인하기」 · 모바일/PC `https://#{안내장링크}`
- 변수: #{병원명} #{환자명} #{병원전화} #{안내장링크} (코드 `src/routes/api.ts` 의 sendAlimtalk 변수와 일치시킬 것 — 현재 코드는 병원명·안내장링크만 넣으므로 템플릿 확정 시 환자명·병원전화를 추가 주입)

## 검수자 참고 의견
발송 상황: 치과에 직접 내원한 환자가 진료실에서 설명을 들은 뒤 "설명 자료를 카카오톡으로 받아보겠다"고 동의한 경우, 병원이 그 자리에서 해당 환자 번호로 1회 발송합니다. 수신자는 당일 내원해 설명을 들은 환자 본인이며(수신자 액션: 내원·설명 청취·자료 수신 동의), 내용은 진료 설명·주의사항·비용 안내로 광고·판촉·혜택 내용이 없습니다. 발송 대행: Patient Connect(페이션트퍼널), 개별 병원의 요청으로 발송되며 메시지에 병원명·병원 문의처를 명시합니다. 병원용 동의 문구: https://connect.patientfunnel.kr/legal-guide
